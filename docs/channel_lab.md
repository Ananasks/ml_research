# Лаборатория моделей трансионосферного радиоканала

В разделе пять вкладок: Кларк–Джейкс; один тонкий фазовый экран; физический
сценарий ПЭС с выбираемым рассеянием; подходы; математические формулы. Это самостоятельные
численные реализации опубликованных уравнений, без заимствования кода.
API: `POST /api/radio/channel-lab`. Параметры ограничены Pydantic-моделью;
результат и конфигурация экспортируются в JSON. Расчёт запускается явно.

## Источники и границы

- [Clarke, 1968](https://doi.org/10.1002/j.1538-7305.1968.tb00069.x):
  изотропное рассеяние, корреляция J0.
- [MathWorks: Doppler spectra](https://www.mathworks.com/help/comm/ref/doppler.html):
  аналитический спектр Джейкса.
- [Rino и соавторы, 2017](https://www.ion.org/publications/abstract.cfm?articleID=15286):
  двумерные фазовые экраны для GNSS и пространственно-временное преобразование.
  Здесь реализован базовый один экран, а не полный алгоритм этой публикации.
- [Распространение углового спектра](https://journals.iucr.org/s/issues/2013/03/00/pp5031/index.html):
  численный принцип Френеля. Знак ниже согласован с exp(+j2πft), обратной
  временной конвенцией относительно обычной оптической записи exp(−jωt).
- [ITU-R P.531](https://www.itu.int/rec/R-REC-P.531/en) и
  [ESA: Ionospheric Delay](https://gssc.esa.int/navipedia/index.php/Ionospheric_Delay):
  эффекты ионосферы, физический слой первого порядка по STEC.

Четвёртая вкладка не воспроизводит «реальный канал» без измерений рассеяния и
калибровки. Ручные значения — исследовательский сценарий, не нормативный
профиль ITU. Из полной рекомендации реализованы только эффекты первого порядка
по ПЭС; нет Фарадея, поглощения, магнитного поля или высших порядков.

## Кларк–Джейкс

На каждом луче независимые случайные углы и начальные фазы:

```
g_l(t) = N^(-1/2) Σ_k exp(j[2π fD cos(α_lk) t + ψ_lk])
E|g_l|² = 1; R_g(τ) = J0(2π fD τ)
S_g(f) = 1/(π fD sqrt(1−(f/fD)²)), |f| < fD
H_scat(ν,t) = Σ_l sqrt(P_l) g_l(t) exp(−j2πντ_l)
```

N — число гармоник на луч; L — число разрешаемых лучей. В узкополосном режиме
L=1. Широкополосный профиль имеет равномерные задержки 0…τmax и мощности
P_l ∝ exp(−3l/(L−1)), нормированные в сумме к единице (при L=1 P=1).
Это сценарный профиль, не вывод из TEC. Реализация не нормируется по своей
выборочной мощности. LOS/Rice не реализован. Fs > 2fD проверяется до расчёта.

## Фазовый экран

q — пространственная частота в циклах/м:

```
Φφ(q) ∝ (q²+L0^(-2))^(-p/2) exp[−q² l0²]
φref = IFFT2(FFT2(w) sqrt(Φφ)), w — белое вещественное гауссово поле
φ_f = φref fref/f, fref = 1575.42 MHz
U_f = IFFT2(FFT2(exp(jφ_f)) exp(+jπ(c/f)z(qx²+qy²)))
h_f(t) = U_f(x0+vt,y0)
```

Постоянная пространственная мода удаляется. RMS φref на конечной сетке
приводится к заданному значению. Это условие силы выбранного сценария, а не
измеренная статистика ансамбля. p, L0 и l0 описывают именно указанный спектр;
не следует подменять их параметрами иной конвенции пространственной частоты.

Сетка периодическая, 128² или 256². Траектория — центральная строка, начинается
в x0=0.1NΔx, использует линейную интерполяцию. При z=0 интерполируется фаза,
затем вычисляется exp(jφ), чтобы интерполяция комплексных отсчётов не создавала
ложные амплитудные сцинтилляции без распространения. При z>0 интерполируется
комплексное поле; необходима проверка сходимости. Повторный проход по экрану
не допускается: vT ≤ 0.8NΔx. При v=0 временная реализация постоянна.

Оценки разрешения: Δx ≤ l0/2; Δx ≤ rF/3;
rF=sqrt(λz/(2π)); NΔx ≥ 4L0. Это диагностические рекомендации, не доказательство
сходимости. Пользователь сравнивает сетки и независимые seed. Разрешение по
времени не создаёт новых пространственных деталей между узлами сетки.

Сохраняется энергия всей периодической плоскости (Parseval, |kernel|=1).
Мощность отдельной траектории может отличаться от единицы. Выводятся карты
φ и |U|² и Dφ(ρ), оценённая по разностям вдоль x без склеивания краёв.
Экран изотропный, гауссов, замороженный; нет нескольких слоёв и анизотропии.

## Физический слой

```
S(t) = 10^16 [STEC0 + rate*t]  [эл/м²]
K(t) = 2π 40.3 S(t)/c
Hion(f,t) = exp(j K(t)/f)
ΔL = 40.3 S/f²; τg = ΔL/c
fion = 40.3/(c fc) dS/dt
H = Hion Hscat
```

STEC0 и rate задаются вручную либо берутся из выбранной точки измеренного или
прогнозного ряда вкладки «ПЭС». В ней уже учтены единицы и переход VTEC→STEC.
Время UTC и тип источника сохраняются в экспорте. Используется локальная
линейная экстраполяция, а не весь суточный ряд на быстрой диагностической сетке.
Отрицательное продолжение STEC отклоняется. Параметры рассеяния независимы.

## Характеристики и их смысл

- Временной h вычисляется на несущей; PSD — Welch без удаления среднего,
  чтобы не потерять спектральную линию постоянной части. Центрированная ACF
  нормирована по дисперсии; для постоянного канала она не определена (`null`).
- S4=std(|h|²)/mean(|h|²) по данной реализации. Это не стандартная GNSS-оценка
  S4 с фильтрацией и коррекцией инструментального шума. СКО развёрнутой фазы
  зависит от окна и тренда, а около нулей амплитуды unwrap неоднозначен.
- АЧХ/ФЧХ — первый момент состояния. Используются 129 равномерных частот в B.
  В физическом широкополосном сценарии удаляются общая фаза K/fc и линейная
  фаза групповой задержки: D=exp[jK(1/(fc+ν)−1/fc+ν/fc²)]. Абсолютные τg и
  φadv выводятся отдельно. В узкополосном режиме отклик идеализирован плоским.
- CIR — fftshift(IFFT(ifftshift(H))). Конечная полоса: Δτ≈1/B, циклический период
  1/Δν. Ось относительно синхронизированного начала; отрицательные координаты
  не означают отрицательную физическую задержку. Длинные хвосты могут свернуться
  по периодическому окну; CIR не заменяет отдельно известный профиль лучей.
- Для независимых лучей Кларка R(Δf)=ΣP_l exp(−j2πΔfτ_l), ΣP_l=1.
  Это корреляция стохастического профиля без детерминированной дисперсии ПЭС.
  Для экрана используется нормированное комплексное среднее по частотным парам
  и до 128 точкам траектории. Это конечная оценка, а не теорема WSSUS.
- Bc — первое пересечение |R|=0.5, с линейной интерполяцией между частотными
  отсчётами. Поиск ограничен примерно B/2. `null` означает «нет пересечения
  в исследованном диапазоне». Это не измеренная бесконечная полоса когерентности.

Проверки: `python -m pytest tests/test_channel_lab.py`. Покрыты отсутствие
экрана, z=0, неподвижный приёмник, энергия Френеля, спектральная плоскость
одного/совпадающих лучей, воспроизводимость, физические размерности ПЭС и
отклонение некорректных параметров.

## Автоматическая подготовка параметров

`POST /api/radio/channel-setup` выполняет быстрый детерминированный подбор,
без генерации случайного поля и моделирования канала. UI обновляет подготовку
при изменении ключевых условий; моделирование запускается отдельной кнопкой
только после успешной подготовки. Экспорт содержит полученную конфигурацию,
источник ПЭС и таблицу происхождения параметров. Ручной режим оставляет полный
контроль над численными и физическими параметрами.

Ключевые величины: fD для Кларка, RMS фазы при 1575,42 МГц для экрана,
TEC/CSV и геометрия для физического сценария. Константы условий опыта
(fc, T, B, seed) доступны отдельно. В ручном физическом вводе можно выбрать
VTEC; M(E) преобразует как среднее, так и локальную производную в STEC.
Данные, уже подготовленные вкладкой «ПЭС», повторно не преобразуются.

Инженерные сценарии:

| Сценарий | RMS фазы, рад | fD, Гц | v экрана, м/с | Лучей / τmax, мкс |
|---|---:|---:|---:|---|
| quiet | 0.2 | 0.2 | 20 | 2 / 0.5 |
| moderate | 0.5 | 1 | 40 | 4 / 2 |
| disturbed | 1 | 3 | 60 | 6 / 5 |

В отдельных статистических вкладках введённый ключевой параметр сохраняется.
В физической вкладке независимые параметры рассеяния берутся из сценария.
Средний TEC никогда не преобразуется в RMS флуктуаций или fD.

Для экрана rF=sqrt(λz/(2π)), L0=4rF, l0=0.4rF с учётом границ модели,
p=11/3. Последние три связи — документированные допущения.
Δx=min(l0/2,rF/3,100м); выбирается минимальная сетка 128² или 256²,
покрывающая 4L0 и траекторию vT/0.8. Если разрешённого размера недостаточно,
подготовка возвращает ошибку с допустимой длительностью. При z=0 явно
принимается опорный сценарный масштаб 100 м; физический rF остаётся нулевым.
Для физического автоматического сценария z=hI — принятое приближение.

Частота отсчётов Кларка min(160,max(40,ceil(20fD))). Если бюджет не позволяет
20-кратный запас, он явно ограничивается с сохранением Fs>2fD. Для экрана
Fs=min(160,max(40,ceil(4v/Δx))). Гармоник на луч 128. Полный список происхождения
возвращается с кодами input, formula, scenario, numerical и текстом зависимости.

Проверки подготовки: `python -m pytest tests/test_channel_setup.py`.
