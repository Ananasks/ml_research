# Расширенный каталог моделей

На вкладке «Модель и обучение» доступны категория, поиск по названию/библиотеке и выбор модели. Категории: линейные модели, деревья и ансамбли, бустинг, нейронные сети, методы опорных векторов, соседние объекты, наивный Байес, дискриминантный анализ, ядерные методы, гауссовские процессы и базовые модели.

Встроенные расширения scikit-learn: ARD Regression, Lars, Lasso Lars, Passive Aggressive, Perceptron, Ridge Classifier, Extra Tree, Nearest Centroid, Kernel Ridge, Gaussian Process и Dummy Baseline. Доступность зависит от задачи: регрессия/классификация. LSTM/GRU/RNN доступны для временного разделения регрессии.

Дополнительные адаптеры: XGBoost, CatBoost и LightGBM. Для каждого есть параметры интерфейса, пространство случайного/Optuna-поиска и поддержка общего pipeline, экспорта, прогнозов и объяснений. XGBoost-классификатор кодирует классы на train и возвращает исходные метки; порядок вероятностей соответствует classes_. CatBoost не создаёт служебные файлы в рабочем каталоге. В этой интеграции категориальные X проходят общий one-hot preprocessing, а не нативную обработку категорий CatBoost.

## Установка

```bash
source .venv/bin/activate
python -m pip install -r requirements-models.txt
```

В текущем окружении подключены **41 семейство: 32 модели регрессии и 27 классификации** (часть семейств общая для обеих задач).

На macOS XGBoost и LightGBM могут требовать OpenMP. Если Homebrew недоступен для записи, можно использовать OpenMP, поставляемый с PyTorch в том же виртуальном окружении:

```bash
python scripts/setup_native_models.py
```

Скрипт на macOS добавляет относительный путь поиска библиотеки в два dylib-файла XGBoost/LightGBM внутри активного venv и обновляет их локальную ad-hoc подпись. Системные директории не изменяются. После обновления этих пакетов скрипт нужно повторить. В текущем окружении этот способ проверен обучением обеих задач. Альтернатива при доступном Homebrew:

```bash
brew install libomp
```

После установки перезапустите Streamlit. Если пакет отсутствует или его нативная библиотека не загрузилась, приложение продолжает работать с остальным каталогом. Причина недоступности видна в полном каталоге. Основной requirements.txt не требует эти дополнительные пакеты.

## Ограничения

Gaussian Process ограничен 2000 строками train, Kernel Ridge — 5000: матричные вычисления требуют значительной памяти. Размер не уменьшается автоматически; выберите меньшую обучающую часть на первой вкладке. Пространства параметров задаются проверенным реестром, а не автоматически всеми аргументами класса. Добавление новой модели требует адаптера и проверки обеих задач, если они поддерживаются.
